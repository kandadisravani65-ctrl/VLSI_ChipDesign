# RTL-to-GDSII: Digital Design and ASIC Implementation

## Overview

This repository documents a practical learning journey through digital hardware design and ASIC implementation. It covers the development of RTL modules, functional simulation, logic synthesis, timing analysis, standard-cell libraries, and physical design using open-source EDA tools.

The work is organized into progressive stages, beginning with the development environment and digital design fundamentals and advancing toward ASIC physical implementation and SoC integration.

## Objectives

- Learn digital logic design and Verilog HDL.
- Develop RTL modules and verify them using testbenches.
- Analyze simulation waveforms and debug design behavior.
- Study synthesis transformations and gate-level netlists.
- Understand timing constraints and static timing analysis.
- Explore standard-cell libraries and the SKY130 technology.
- Learn floorplanning, power distribution, placement, clock-tree synthesis, and routing.
- Study the integration of RTL components into a System-on-Chip design.
- Maintain reproducible experiments and document technical observations.

## Project Roadmap

### 00 — Environment Setup
Prepare the Linux environment and document tool installation and configuration.

### 01 — Digital Design Fundamentals
Review combinational logic, sequential circuits, registers, counters, and finite-state machines.

### 02 — Verilog RTL Design
Implement digital modules and study RTL coding practices.

### 03 — RTL Simulation
Create testbenches, run simulations, and inspect waveforms.

### 04 — RTL Optimization
Study coding styles, logic simplification, and synthesis-friendly RTL.

### 05 — Synthesis and Gate-Level Simulation
Explore synthesis results, mapped netlists, and RTL versus gate-level behavior.

### 06 — Timing Analysis
Study timing constraints, clock definitions, setup and hold checks, and timing reports.

### 07 — Standard-Cell Libraries
Explore cell libraries, technology files, cell characteristics, and library mapping.

### 08 — Floorplanning and Power Integrity
Study die and core dimensions, utilization, aspect ratio, power planning, and decoupling.

### 09 — Placement and Clock-Tree Synthesis
Explore standard-cell placement, placement constraints, and clock distribution.

### 10 — Routing and Signoff
Study routing, design-rule checks, and implementation verification.

### 11 — SoC Integration
Explore the BabySoC architecture and document the integration of its design components.

## Documentation Format

Each experiment will document:

1. Objective and design concept
2. Required tools and files
3. Implementation procedure
4. Commands used
5. Verification results
6. Screenshots and reports
7. Key observations and conclusion
